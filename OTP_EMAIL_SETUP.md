# OTP Email Setup (Gmail)

This guide explains how to send real OTP emails to reset the admin password using your Gmail account.

## Requirements

- Gmail account (e.g. `oliyaruviprinters@gmail.com`)
- **2-Step Verification** enabled on that Google account
- **App Password** (16-character password generated by Google)

## Step 1: Enable 2-Step Verification

1. Go to [Google Account Security](https://myaccount.google.com/security)
2. Under "How you sign in to Google", click **2-Step Verification**
3. Follow the steps to enable it (phone verification)

## Step 2: Create App Password

1. Go to [App Passwords](https://myaccount.google.com/apppasswords)
2. Sign in if prompted
3. Under "Select app" choose **Mail**
4. Under "Select device" choose **Other** and type "Oliyaruvi Billing"
5. Click **Generate**
6. Copy the **16-character password** (e.g. `abcd efgh ijkl mnop`)

## Step 3: Configure Backend

Edit `backend/.env`:

```env
GMAIL_USER=oliyaruviprinters@gmail.com
GMAIL_APP_PWD=abcdefghijklmnop
RESET_EMAIL=oliyaruviprinters@gmail.com
```

- `GMAIL_USER` – Your Gmail address (sender)
- `GMAIL_APP_PWD` – The 16-character App Password (no spaces). Use `GMAIL_APP_PWD` because some tools filter variables with "PASSWORD" in the name.
- `RESET_EMAIL` – Email allowed to receive OTP (usually same as GMAIL_USER)

## Step 4: Restart Backend

Restart the backend server so it picks up the new `.env` values.

## Optional: Custom Sender Name

```env
GMAIL_FROM_NAME=Oliyaruvi Printers
```

## Troubleshooting

| Issue | Solution |
|-------|----------|
| "GMAIL_USER and GMAIL_APP_PWD required" | Add both to `.env` in the backend folder |
| "Invalid login" | Use App Password, not your normal Gmail password |
| "Only X can reset" | Ensure the email you enter matches `RESET_EMAIL` in `.env` |
| OTP not received | Check spam folder; verify sender is your Gmail address |
| "read ECONNRESET" / "Connection to Gmail failed" | Add **RESEND_KEY** as fallback (see below). Resend uses HTTPS and works when Gmail SMTP is blocked. |

## Resend (fallback when Gmail is blocked)

When Gmail SMTP is blocked by firewall/network:

1. Sign up at [resend.com](https://resend.com) (free)
2. Create an API key at [resend.com/api-keys](https://resend.com/api-keys)
3. Add to `backend/.env`:
   ```env
   RESEND_KEY=re_your_key_here
   ```
4. Restart backend. OTP will be sent via Resend when Gmail fails.

## Why Gmail?

- Emails come from your own Gmail address
- Better deliverability than third-party senders (e.g. @resend.dev)
- No extra setup for domains or spam filters
